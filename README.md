Farmer Assistance & Weather Forecasting Android App

Overview

Farmer Assistance & Weather Forecasting is an Android application built using Kotlin that combines real-time weather information with crop management and farming guidance.

The application helps users monitor weather conditions, create farming projects, access crop-related information, and receive farming recommendations through both AI-assisted and offline guidance systems.

---

Features

Weather Forecasting

- Real-time weather updates
- City-based weather search
- Current weather information
- Forecast data display

Farmer Project Management

- Create and manage farming projects
- Select crops for cultivation
- Track farming activities

Crop Guidance System

- Offline crop dataset stored using Room Database
- Information for multiple crops including:
  - Soil requirements
  - Growth stages
  - Temperature conditions
  - Pest information
  - Farming recommendations

AI-Assisted Support

- Gemini API integration for farming assistance
- Offline guidance system available as fallback
- Structured crop recommendations through local database

Authentication

- User registration and login using Firebase Authentication
- Session management
